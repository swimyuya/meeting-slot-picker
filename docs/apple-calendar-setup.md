# Apple Calendar (iCloud) 連携手順

「日程ピッカー Pro」で Apple Calendar を連携するには **アプリ用パスワード** が必要です。Google / Outlook のような OAuth ワンクリック連携と違い、初回だけ少し手間がかかります（Apple が外部連携用 OAuth API を提供していないため）。

## 所要時間: 約 3 分

## 事前条件

- ✅ Apple ID で **2 要素認証 (2FA)** が有効になっていること
  - 無効だとアプリ用パスワードを生成できません
- ✅ 接続したい iCloud カレンダーを使っている Apple ID

## 手順

### 1. appleid.apple.com にサインイン

https://appleid.apple.com を開く → ご自身の Apple ID でサインイン

### 2. 「サインインとセキュリティ」を開く

サイドメニュー or トップ画面から「**サインインとセキュリティ**」を選択

### 3. 「アプリ用パスワード」を選択

セクション内に「**アプリ用パスワード**」という項目があります（無い場合は 2FA が無効になっています）。

### 4. 「+ アプリ用パスワードを生成」

ラベルを入力するダイアログが出ます。**「日程ピッカー Pro」** などわかりやすい名前を入力 →「作成」。

### 5. 16 文字のパスワードをコピー

`abcd-efgh-ijkl-mnop` のような形式で 16 文字のパスワードが表示されます。**この画面を閉じると 2 度と見られない** ので、その場でコピーしてください（クリップボードへ）。

### 6. 「日程ピッカー Pro」に貼り付け

[https://meeting-slot-picker-pro.vercel.app](https://meeting-slot-picker-pro.vercel.app) を開いて:

1. 「**Apple Calendar と連携する**」をクリック
2. モーダルに以下を入力:
   - **Apple ID メール** (例: `you@icloud.com`)
   - **アプリ用パスワード** (Step 5 でコピーしたもの。**ハイフンは自動除去**されます)
3. 「**連携する**」をクリック

→ 接続成功 → カレンダー画面に薄ピンクのバーで iCloud 予定が表示されます。

## 連携解除

設定 → 連携状態 → Apple Calendar の「**解除**」ボタンをクリック。
保存されているメールとパスワードは即座に削除されます。

## 漏洩・取り消し対応

アプリ用パスワードが漏洩した・解除したい場合:

1. https://appleid.apple.com →「サインインとセキュリティ」→「アプリ用パスワード」
2. 該当パスワードの **「×」削除** or **「取り消し」**

→ 即座に iCloud 側で無効化されます。日程ピッカー Pro 側も再連携が必要です。

## トラブルシューティング

### Q. 「アプリ用パスワード」のセクションが見当たらない

→ 2 要素認証 (2FA) が無効になっています。「サインインとセキュリティ」内の「2 要素認証」を **有効化** してください。

### Q. 「Apple ID またはアプリ用パスワードが正しくありません」と出る

→ いずれかの可能性:
- メールが Apple ID と一致しない (大文字小文字に注意)
- 16 文字のうち打ち間違いがある
- 既に取り消されているアプリ用パスワード

新しいアプリ用パスワードを再生成して、もう一度試してください。

### Q. 連携できたが予定が表示されない

→ 連携対象の iCloud カレンダーに今週・来週の予定がない可能性。実際に iCloud に予定があるかを iCloud.com で確認してください。

### Q. iCloud 共有カレンダーは見れる？

→ 自分が iCloud 上で受信している共有カレンダーは原則同じ Apple ID 配下にあるため取得されます (詳細検証中)。

## セキュリティ

- アプリ用パスワードは **Google Workspace の「アプリパスワード」と同等** の役割で、Apple ID 本体のパスワード変更や 2FA 設定変更はできない制限付き credential です
- 保存先:
  - **macOS Tauri 版**: macOS Keychain
  - **iPhone / PC PWA**: IndexedDB (origin 単位で隔離、PWA アンインストールで削除)
  - **Chrome 拡張機能**: chrome.storage.local (拡張機能削除で消去)
- サーバには **毎回のリクエストで送るだけで保存しない**
